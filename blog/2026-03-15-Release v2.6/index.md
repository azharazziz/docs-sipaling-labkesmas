We are pleased to announce the release of **version 2.6 (V2.6)** of Portal Labkesmas. This update introduces several new features and improvements aimed at strengthening system administration, enhancing communication capabilities, and improving overall platform stability.

This release focuses on expanding system functionality through new modules, improving existing workflows, and refining user experience based on ongoing development and operational needs.

<!-- truncate -->

## What's New in Version 2.6

### System Administration Improvements
- Added **User Impersonation** feature to allow administrators to temporarily access the system as another user for troubleshooting and support.
- Added **Assign Role to Users** functionality with a modal interface.
- Redesigned **Roles management layout** for clearer permission visibility.

### Security Enhancements
- Implemented **password expiration policy** with a modal prompt that requires users to update their password when it expires.

### Document and ISO 17025 Management
- Improvements to the **ISO 17025 document management module**.
- Fixes and refinements to document handling to ensure better stability and consistency.

### Video Conference Integration
- Introduced **Video Conference module** with **Zoom integration**.
- Added **WhatsApp notifications** for Zoom meeting reminders and related events.

### API Improvements
- Added **API endpoints for accessing sample registration data** to support system integrations.

### Localization and Forms
- Improved **attendance form localization synchronization** for better multi-language support.

### System Reliability Improvements
- Improved **WhatsApp queue logging**, ensuring logs are only generated after all retry attempts fail.
- Fixed **Zoom meeting ID precision issues** by treating meeting IDs as strings.

We hope these updates make **Portal Labkesmas** more efficient and reliable for supporting laboratory operations and collaboration.

We appreciate your continued feedback and support as we continue improving the platform.
