We are excited to announce the release of version 2.5 (V2.5) of our platform, which brings a host of new features and improvements designed to enhance user experience and functionality. This update focuses on optimizing performance, introducing new tools, and refining existing features based on user feedback.
<!-- truncate -->
## What's New in Version 2.5
### Some UI/UX Improvements
- Enhanced navigation menus for easier access to key features
- Improved responsiveness for mobile and tablet devices
- Updated color schemes and themes for better visual appeal
- Brand new homepage design to highlight important sections
- Brand new dashboard design for better user interaction
- Brand new login page design for a more welcoming experience

### Office Performances Modules
- Addition of the Performance module
  - Performance Report Generation
  - Performance Tracking Dashboard
  - Customizable Performance Metrics

### Workplan Modules
- Addition of the Workplan module
  - Workplan Creation and Management
  - Progress Monitoring Tools
  - Publication of Workplan Reports to Public Services

### Samples Numbering Modules
- Addition of the Samples Numbering module
  - Automated Sample Number Generation
  - Sample Tracking System
  - Integration with Laboratory Information Management Systems (LIMS)

We believe these new features and improvements in version 2.5 will significantly enhance your experience and provide you with more powerful tools to manage your tasks effectively.

We encourage all users to explore the new functionalities and provide feedback to help us continue improving our platform. Thank you for your continued support!
